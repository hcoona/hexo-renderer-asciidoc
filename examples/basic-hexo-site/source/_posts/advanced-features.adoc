== Callouts and Code Annotations

Source code with callouts:

[source,python]
----
def fibonacci(n):
    if n <= 1:
        return n  # <1>
    return fibonacci(n-1) + fibonacci(n-2)  # <2>

print(fibonacci(10))
----
<1> Base case: return n when n is 0 or 1
<2> Recursive case: sum of previous two numbers

== Keyboard Shortcuts

Press kbd:[Ctrl+C] to copy and kbd:[Ctrl+V] to paste.

The keyboard shortcut for save is kbd:[Ctrl+S] on Windows or kbd:[Cmd+S] on Mac.

== UI Elements

Click on the btn:[Save] button to save your work.

Navigate to menu:File[Open > Recent Files] to access recently opened documents.
