= Asciidoc Renderer for Hexo

Add support for Asciidoc. This plugin uses link:https://www.npmjs.com/package/asciidoctor.js[asciidoctor.js] as render engine.

== Install

----
$ npm install hexo-renderer-asciidoc --save
----

== Development

=== Toolchain bootstrap

Install the pinned tool versions via https://mise.jdx.dev/[mise], then install Node dependencies and register the git hooks powered by https://github.com/jdx/hk[HK].

[source,bash]
----
mise install
pnpm install
hk install
----

=== JavaScript / TypeScript 开发

* 现有运行时代码依旧是 CommonJS (`index.js` + `lib/renderer.js`)，以保证 Hexo 用户无需额外迁移。
* `tsconfig.json` 打开了 `allowJs`，所以可以在原有 JS 文件夹内逐步引入 `.ts` 文件；
* 想完全用 TypeScript 写新模块时，可以把源码放进 `src/`，再用 `pnpm build` 将 `.ts` 转译到 `dist/` 做验证。`tsconfig.build.json` 默认只会处理 `src/**/*.ts(x)`，因此不会影响当前 JS 产物。
* `types/index.d.ts` 提供了 Hexo renderer、`hexo` 全局以及 `lib/renderer` 的最小类型定义，方便在 IDE 内获得补全，也能让外部项目以 TS 方式消费本插件。

[source,bash]
----
pnpm typecheck    # 对 JS/TS 源码进行类型检查（不生成文件）
pnpm build        # 将 src/ 下的 TypeScript 构建到 dist/
----

=== Linting and formatting

Biome 负责 JS/TS/JSON（`hk` 的 `js-biome` 与 `json-biome` 步骤涵盖了 `.js/.cjs/.mjs/.ts/.tsx/.jsx/.cts/.mts/.json/.jsonc/.json5`），Prettier 专注 Markdown。`hk` 将这些步骤统一进 `pre-commit` / `pre-push` / `check` / `fix` 钩子，手动执行 `hk check` 就能复刻 CI 体验。

[source,bash]
----
pnpm lint          # Biome + Markdown 校验
pnpm format        # Biome + Markdown 自动格式化
hk check           # 执行所有钩子
hk fix             # 对所有支持 fix 的步骤尝试自动修复
----

=== 发布 / npm 发布准备

1. `pnpm typecheck && pnpm test`（若需要覆盖测试）。
2. `pnpm run build`（如果加入了新的 `.ts` 源码，会在 `dist/` 生成 CommonJS 产物）。
3. `pnpm publish`（Prepublish 钩子会自动跑 `pnpm build`，因此可在 CI 中直接 `pnpm publish --access public`）。
